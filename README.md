# The Gravity Detective

An interactive educational experience about one of the greatest mysteries in the history of physics.

## The Question

How does the Sun influence the Earth across empty space?

Before the concept of fields existed, this question had no satisfactory answer.

## Goal

Investigate the evidence, test hypotheses, and discover the problem that eventually led to the concept of fields.

## Topics

- Newtonian Gravity
- Action at a Distance
- History of Physics
- Field Theory
